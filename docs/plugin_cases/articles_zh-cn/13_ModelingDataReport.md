本插件通过 MIDAS API 全量采集 GEN NX 中已打开模型的定义数据（结构形式/楼层/材料/截面/边界条件/荷载/
分析选项），并自动生成为可直接附于结构计算书附录的“建模审查报告”（PDF、Excel）。

## 主要功能

**01. 缩短模型校核时间**
通过对 GEN NX 所建模型的全量检查功能，缩短资深与初级工程师确认建模内容所需的时间。

**02. 防止遗漏**
防止因不清楚菜单位置而容易遗漏的自重、边界条件、刚度系数等项目出现遗漏。

**03. 减轻审查文档编制负担**
连层间位移与不规则性评估都会自动整理完成，抗震相关审查文档的编制负担随之减轻。

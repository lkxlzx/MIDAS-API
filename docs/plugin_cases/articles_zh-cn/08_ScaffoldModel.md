本插件是一款面向实务的工具，将 MIDAS GEN NX 中单排脚手架与双排脚手架从模型创建、荷载施加、结构分析、
Steel Code Check，到结果图像保存以及脚手架结构验算书编制的主要过程全部自动化。

## 主要功能

**01. 自动生成脚手架模型**
按输入的条件自动生成单排脚手架与双排脚手架模型。

**02. 自动施加荷载与分析条件**
自动施加风荷载以及声屏障、防坠落网、作业踏板荷载，并自动施加边界条件与荷载组合。

**03. 结构分析与 Steel Code Check**
顺序执行结构分析与 Steel Code Check，并以 OK 或 NG 确认验算结果。

**04. 保存分析结果图像并编制验算书**
自动保存分析结果图像，并生成纳入输入信息与结果图像的脚手架结构验算书。

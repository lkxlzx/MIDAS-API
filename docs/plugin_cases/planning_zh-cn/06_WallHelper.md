## 1. 概述

**WallHelper** 是在单一画面中，将 GEN NX 的矩形墙体（Wall）按基准长度分割（Split），
并按周边节点网格进行清理（Cleanup）·合并（Merge），同时按布置方向自动修正的 Plug-in
。它将实务中由各负责人各自处理方式不同的墙体分割·清理作业以同一规则自动化，从而
提高模型一致性。

## 2. 问题定义

- 将大型矩形墙体按一定长度单位划分（例：配合层高·开洞位置等）以细化单元的
  作业在实务中反复出现，但手工操作时各负责人的分割基准不同，模型
  一致性差。
- 反复分割·修正后，不必要地重叠或被过度拆碎的墙体单元·节点不断堆积，导致模型
  变得凌乱，而清理这些内容靠手工也很繁琐。
- 字幕："本插件是为快速解决实务中反复出现的墙体相关修正作业而
  制作的。"

## 3. 目标用户

- 在 GEN NX 中处理墙体（Wall）单元的结构建模者·设计者，尤其是由多人分工建模导致
  墙体分割基准容易各异的协作项目的实务人员。

## 4. 核心概念 / 差异化点

- **"选择→按钮"两步结束的极端简洁**：正如"使用方法就是选择后按下按钮即可"这一
  标语，仅凭 ① 选择墙体 → ② 点击功能按钮（[墙体分割] 或 [墙体清理]）两步，
  全部作业即告完成。没有单独的选项窗口或复杂设置。
- **基于基准长度的均匀分割**：仅用"基准长度(m)·分割单位"这一个数值即可将所选矩形墙体按相同
  间隔自动分割—把各负责人不同的划分习惯统一为一个规则。
  视频示例：以基准长度 1.0m 分割所选的 108 个墙体，结果为"API 调用：7 次"处理完成。
- **识别周边节点网格进行清理**：[墙体清理] 按钮按周边节点网格清理·合并重复或不必要的
  墙体单元·节点—不是简单删除，而是在保持网格一致性的前提下清理。
- **分割·清理·合并 3 项功能在同一窗口中顺序使用**：墙体分割（第 1 段）→ 清理不必要的墙体·节点
  （第 2 段）→ 整个结构物墙体 Cleanup 及最终确认（第 3 段）为止，在一个侧边面板中连续
  执行的实操流程进行演示。

## 5. 工作流

### Step 1 — 连接 API 并设置基准值

- 在 Wall Helper 面板输入 `MAPI-Key`。
- 输入 `基准长度(m)·分割单位`（例：1.0）。

### Step 2 — 墙体分割（第 1 段）

- 在 GEN NX 画面中选择待分割的墙体区域。
- 点击 [墙体分割] 按钮 → 按基准长度自动分割墙体。
- 完成时"墙体分割完成"弹窗中显示 `对象：GEN 当前选择 108 个`、`API 调用：7 次`—即
  108 个墙体的分割在内部由 7 次 API 调用批量处理（推测并非每个单元 1 次，而是通过批量
  调用做了优化）。
- 随后画面接续以 GEN NX 的 `Query Dialog` 窗口（Node 查询）直接查询已分割墙体的节点（Node）
  编号（例：61、571），确认 Node·Element 构成是否按预期生成—其特点在于
  结果验证不使用 Plug-in，而用 GEN NX 自带的查询功能。

### Step 3 — 清理不必要的墙体与节点（第 2 段）

- 在画面中用拖拽指定待清理·删除的墙体区域进行选择。
- 点击 [墙体清理] 按钮 → 显示"墙体清理中..."进度提示后，按周边节点网格自动删除·整理
  重复或不必要的墙体单元及节点。

### Step 4 — 整个结构物墙体 Cleanup 及最终确认（第 3 段）

- 在整体建模画面中再次用拖拽选择墙体清理的对象范围。
- 以整个结构物规模重新执行 [墙体清理] 流程 → 节点及 Wall 单元被自动删除·整理。
- ⚠️ 进入本段后立即捕捉到面板底部状态显示为"墙体合并完成"的画面—[墙体合并]
  按钮被明确点击的画面本身因帧采样间隔未被捕捉到，但推测将被分割的部分墙体合为一体的
  合并步骤在清理过程前后被执行。
- 最终一边复查整理后的整体 3D 结构物模型，视频结束。

## 7. 输入数据规格

- **基准长度(m)**：分割单位（例：1.0m）—必填输入。
- **作业对象**：用户在 GEN NX 画面中直接选择的 Wall 单元（矩形墙体）。

## 8. 输出 / 生成结果

- 按基准长度分割后的 Wall 单元·Node（墙体分割）。
- 移除了重复/不必要 Wall 单元·Node 的整洁模型（墙体清理）。
- 零散墙体部分合为一体的模型（墙体合并）。

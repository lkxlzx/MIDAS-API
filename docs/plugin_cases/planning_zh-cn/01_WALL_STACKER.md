## 1. 概述

将结构图纸（DXF）按楼层输入后，自动识别墙体中心线，并在 GEN NX 分析模型中**自动生成墙单元（Wall）与洞口过梁（Lintel Beam）**的 Plug-in。以"分层图纸输入 → 候选/设置确认 → Gen NX 生成"的三步向导（Wizard）形式运行，可一次登记多个楼层的 DXF 进行批量处理。

## 2. 问题定义（要解决的痛点）

- 把结构图纸的墙体中心线转换到 GEN NX 的节点·单元，楼层越多重复劳动累积越大。
- DXF 是人绘制的图纸，因此**墙体交汇处线条未精确相接**、或同一接合处却逐层、逐区段坐标存在细微错位的情况很常见。照此直接生成节点会导致节点重复创建、单元断裂（断节），并使无用节点增多，降低分析模型质量。
- 洞口（门窗等）上方的过梁属于墙体建模之外需另行处理的项目，容易被遗漏。

## 3. 目标用户

制作 RC 剪力墙结构（公寓/商住混合等）初期分析模型的结构工程师。尤其是需要对多个楼层的墙体反复建模的实务人员。

## 4. 核心概念 / 差异化点

- **基于 DXF 图层的自动识别** — 只需指定"中心线图层"与"墙体图层"，其余图形判读由 Plug-in 处理（其他图层无需特意删除）。
- **端点（节点）自动修正** — 以容许距离为基准，自动对齐并合并图纸上细微错位的接合部，并将修正前/后进行可视化比对，由用户批准的结构（并非全自动，而是**复核后批准**的半自动方式）。
- **过梁自动生成选项** — 设定洞口宽度的最小/最大标准，仅对满足条件的洞口自动布置过梁，并可将单项从列表中排除。
- **PLAN 复用（库）** — 同一平面可映射到多个楼层（标准层重复等），无需为每个楼层重新准备 DXF。

## 5. 工作流（基于视频分析的三步详解）

### Step 1 — 分层图纸输入（STEP 1 · DRAWINGS）

| 画面元素 | 动作 |
| --- | --- |
| AUTO STORY | 输入"创建楼层数"与"自动建模起始高度"，点击**"生成楼层列表"** → 自动填入 Story 信息。生成后可逐项编辑 |
| PLAN LIBRARY（PLAN 保管库） | 通过拖放或文件浏览器批量登记 DXF 文件。已登记的 DXF 以卡片形式列出（文件名、登记时间、单独删除按钮） |
| 应用范围批量设置 | 指定"应用范围（起始~结束楼层）"+ "PLAN 批量分配"（从已登记的 PLAN 中选择）+ "层高批量分配(m)"后点击**"应用"** → 将同一 PLAN·层高一次性映射到多个楼层 |
| 分层表格 | 以表格形式查看并修改每层（1层~N层）的**层高**与 **PLAN 选择**（下拉菜单，可单独指定） |

- 顶部状态栏显示进行步骤(1/2/3)，并用输入项的**脉动（pulse）高亮效果**提示下一个动作 — 在 UI 层面支持初次使用者的上手引导。
- 右上角"模型已连接"指示器，常时显示 GEN NX 连接状态。

### Step 2 — 候选/设置确认（STEP 2 · 候选/设置确认）

**2-1. 分层图层与提取条件**

| 参数 | 说明 |
| --- | --- |
| 全部图层 → 中心线图层 / 该层墙体图层 | 在 DXF 的全部图层列表中用左右箭头指定"中心线图层"1个、"墙体图层"1个（每个楼层各自重复） |
| 容许距离(mm) | 节点自动合并时视为"同一接合部"的坐标误差容许范围（默认 150） |
| 最小长度(mm) | 短于此长度的墙段属于忽略/合并对象（默认 300） |
| 重复布置间隔(mm) | 墙体重复布置判定间隔（默认 250） |
| 端部修正(mm) | 墙体端头修正距离（默认 50） |
| 坐标比例 | 图纸坐标单位换算系数（默认 0.001，即 mm→m） |
| 厚度(m) / 厚度 ID / 混凝土强度 / 材料 ID（自动） | 该层墙体的厚度·材料属性。材料 ID 按厚度·强度组合自动编号（例：`9000: 24MPa_Wall Stacker`） |
| AUTO LINTEL（洞口过梁自动生成）— ON/OFF 切换 | ON 时显示下方细项选项 |
| 最小/最大洞口宽(mm) | 仅对该范围内的洞口自动生成过梁（默认 300~4000） |
| 过梁高度(m) / 梁宽（=墙厚） | 过梁截面尺寸 |
| 截面 ID / 检出过梁数 | 自动编号的截面 ID，以及满足条件而检出的过梁总数（例：25个） |
| PLAN 预览 | 通过分层标签（BASE/1层/2层/…）切换，目视确认提取出的墙体·过梁线条。底部显示 BASE 线（59）、修正数（3）、待批准（0）、复核项（116）等汇总计数器 |

**2-2. 端点修正（自动建模复核 — 修正）**

- 在图纸叠加图形中高亮显示细微错位的节点对（例："修正1：3层→2层，偏差距离 7.5mm"）。
- 在列表中对各修正项单独**"批准"**后，图形中对应节点变为绿色，可直观确认其已合并为一个节点。
- 通过顶部标签切换"重叠查看 3（重叠项）" / "间梁复核 25（过梁复核 25 项）" / "重置复核"。

**2-3. 过梁复核**

- 在同一图形上以橙色虚线/粗红线显示过梁候选。
- 在列表中可对各个过梁项（例："过梁1，1层，2612mm"）单独**"排除"**处理 — 用户可筛除自动检出的过梁中不需要者。
- 底部提供**"导出候选 CSV"**、**"保存复核 JSON"**按钮 — 可将复核结果保存/复用到外部文件。

### Step 3 — Gen NX 墙体生成（STEP 3 · CREATE）

| 项目 | 内容 |
| --- | --- |
| 执行 | 点击一次"在 GEN NX 中创建墙体"按钮，一次性生成全部楼层 |
| 结果汇总 | 显示"墙体创建完成！"+ 生成的**节点数**·**墙体数**（例：节点 197 个，墙 109 个） |
| 近期作业（操作日志） | 画面上按顺序显示实际的 API 调用历史（见下文 6 节） |
| 重新生成 | 可用"再次生成"按钮以同一设置重跑 |
| 生成数据详情查看 | 可在独立面板中查看生成的详细明细 |

生成后立即在 GEN NX 3D 视图中反映墙体·过梁，并确认 Tree Menu 中 `Structures > Nodes 197 /
Elements 134 (Beam 25 + Wall 109)`、`Properties > Material 0 / Section 1 / Thickness 1`
已被填充。最终画面提示文案：**"如需完成分析模型，请自行补充柱与梁构件"** — 明确本 Plug-in 仅负责墙体·过梁，柱、楼板梁等其余构件需另行建模。

## 7. 输入数据规格

- **格式：** DXF（视频中出现于 AutoCAD 2023 中准备文件的画面 — 是否依赖特定版本未确认）
- **图层要求：** 只要该层具备"墙体图层"与"中心线图层"即可使用。其他图层（尺寸线、参考线等）可在 Plug-in 中调节，无需预先整理。
- **必要限制：** **各层图纸的原点必须一致**（视频内提示文案原话）。
- 同一个 PLAN(DXF) 可复用于多个楼层（标准层映射）。

## 8. 输出/生成结果

- 直接反映到 GEN NX 模型的 **Node**、**Wall(Plate 系) Element**、**Lintel Beam Element**，以及其所需的 **Material / Section（过梁截面）/ Thickness（墙体厚度）** 属性全套。
- 复核阶段产出物：修正/过梁候选 **CSV**、复核状态 **JSON**（推测用于重做作业时载入 — 视频中未确认"载入"动作本身）。

## 9. 限制事项与局限（依据视频·文档）

- 仅创建墙体·过梁 — **柱、楼板梁等其余骨架需用户另行添加**，才构成完整的分析模型（最终画面提示文案）。
- 各层图纸原点错位时无法正常工作。
- 端点修正·过梁生成并非全自动，而是**需用户批准的半自动工作流** — 即不适合无人值守批处理（batch），复核阶段以人工介入为前提。
- 相较原文文章（按关注/浏览量计 33·420），仅凭视频无法确认误差容许范围推荐值的依据、过梁截面计算逻辑的细部算式 — 实际立项/开发时需向原开发方确认。

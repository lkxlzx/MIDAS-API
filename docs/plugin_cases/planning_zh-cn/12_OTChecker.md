## 1. 概述

**OT Checker SE（Over Turning Checker）** 是基于 GEN NX 分析结果与用户输入的设计条件，验算结构物在
风荷载及地震作用下抗倾覆（Overturning）稳定性的 Plug-in。它从 GEN NX 自动读取倾覆验算所需的固定荷载
支座反力与倾覆力矩，按确认分析结果 → 抗倾覆稳定性验算 → 控制条件判定 → 输出报告这一连续的 4 步流程
完成。

## 2. 问题定义

- 风荷载·地震作用下的结构物倾覆验算，需要把 GEN NX 分析结果（固定荷载反力、各荷载工况的倾覆力矩）
  誊写到单独的计算表中才能求出抵抗力矩·安全系数，属于重复性作业。
- 采用强度设计法与容许应力设计法等验算方法不同时，荷载组合·安全系数标准也随之改变，每次都要重新
  推导公式，十分繁琐。
- 模型中未包含的基础·墙体自重（贡献抵抗力矩的要素）需另行反映，而这很容易漏项。

## 3. 目标用户

- 需按 KDS 荷载组合或安全系数标准验算结构物在风荷载·地震作用下抗倾覆稳定性的结构设计者。
- 包含首次接触该作业流程的新用户（原文 4 大功能中的第 1 项即"面向初次使用者的分步引导"）。

## 4. 核心概念 / 差异化点

- **顶部状态提示栏 + 脉动高亮效果**：始终显示 4 阶段（①输入设计条件 ②确认联动数据 ③验算 ④报告）的
  进行状态，并用蓝色提示卡片对下一个输入栏位做脉动高亮 —— 与 #7 ScaleUp 相同的上手引导设计模式。
- **内置力臂距离（Lx·Ly）概念指引**：用"对称平面（质心位于中央）/非对称平面（质心偏心）"2 种 CASE
  图示直接讲解"Lx·Ly 是到哪里的距离"，把用户容易搞错的力臂距离定义以视觉方式讲清楚。
- **可同时选择 2 种验算方法**：KDS 荷载组合验算（强度设计法/容许应力设计法中选一）与安全系数验算
  （要求安全系数 SF_req，默认值 1.5）可重复勾选，并按各方法分别给出判定卡片。
- **反映模型外元素的自重**：可添加多个基础自重（面积 A、厚度 t、单位重量 γ → 自动计算 W）与墙体自重
  （平面总长 L、墙体厚度 t、层高 H、单位重量 γ），以免漏掉 GEN NX 模型中实际未建模的基础·挡土墙对
  抵抗力矩的贡献。同时明示警告"若重复输入模型中已包含的构件，重量会被重复叠加"。
- **按结构形式的倾覆概念图（仅供报告附件，不影响计算）**：从钢结构/钢筋混凝土结构/基础结构 3 种中
  选择并把图示自动附入报告，同时注明"该图为报告附件用图像，不影响计算" —— 在 UI 中把计算逻辑与
  文档化要素分离，避免用户混淆。
- **可直接查阅联动的原始数据**：在"GEN NX 原始数据确认"下拉框中可逐一选择实际取回的 6 张原始表（静力
  荷载工况、反应谱荷载工况、固定荷载支座反力、按方向的倾覆力矩 4 种）直接查看原始响应数据 —— 与 #7
  ScaleUp 的"GEN NX 数据来源与原始表"功能相同的透明度设计模式。
- **控制条件判定及自动求出确保稳定所需的固定荷载**：按各荷载方向·验算方法的组合判定 OK/NG，NG 时把
  "确保稳定所需的固定荷载"（例：需追加 175.94 kN）以柱状图可视化 —— 不止于简单判定，还定量给出
  "还需要多少"。

## 5. 工作流

### Step 0 — 在 Apps 中运行

- 在 GEN NX `Apps` 选项卡中选择 "OT Checker SE" → 运行前确认："请在 GEN NX API Settings 中确认 API
  Connection 状态为 Connect 后再按 Run 按钮"，"请在已生成固定荷载、风荷载及地震作用分析结果的模型中
  运行。"

### Step 1 — 输入设计条件

- **倾覆验算输入**：Lx（质心到 X 方向最外端的距离，质心居中时为 X 轴/2）、Ly（同理为 Y 方向）——
  用 "Lx·Ly 输入帮助" 按钮提供对称/非对称平面 2-CASE 指引弹窗。
- **验算方法**：`KDS 荷载组合验算`（选择强度设计法/容许应力设计法）+ `安全系数验算`（要求安全系数
  SF_req，默认 1.5）—— 可重复勾选，各方法的结果在各自独立的卡片中显示。
- **模型外元素的自重**：基础自重（+添加基础）、墙体自重（+添加墙体）—— 以面积·厚度·单位重量自动
  计算 W。
- **按结构形式的倾覆概念图**：选择钢结构/钢筋混凝土结构/基础结构（报告附件用，与计算无关）。选择后
  连同概念图摘要显示模型固定荷载 ΣD.L、总竖向荷载 ΣV、基础自重 Wf。

### Step 2 — 确认联动数据（自动联动 GEN NX 结果）

- 点击"读取 GEN NX 分析结果"按钮 → 自动读取固定荷载反力（ΣD.L，固定荷载工况：默认 DEAD LOAD，也支持
  直接输入）。
- **荷载工况映射及 Mo**：对风荷载 X/Y 方向、地震作用 X/Y 方向分别用下拉框选择 GEN NX 工况（例：
  WX1[ST]、WY1[ST]、EX1[ST]、EY1[ST]），即自动读取各方向的倾覆力矩（Mo）（也可改为直接输入）。当地震
  作用 Y 方向基础层验算弯矩为 0 时，自动显示警告"地震荷载 Y 方向基础层验算弯矩为 0。请确认细部设置及
  方向" —— 事先侦测错误的荷载工况选择。
- **GEN NX 原始数据确认**：在下拉框中选择原始表直接查阅实际读取结果 —— 该清单中原样暴露了下文第 6 节
  表中的 API 名称。

### Step 3 — 验算（抗倾覆稳定性验算）

- 点击"进行验算"按钮 → 确认 ΣD.L(84.53) + ΣW(86.40) = ΣV(170.93 kN) 的合计后执行。
- **STABILITY MARGIN**（确保稳定所需的固定荷载）：按方向（风荷载 X/Y、地震作用 X/Y）以柱状图显示当前
  ΣD.L·所需 ΣD.L·需追加的固定荷载。例：风荷载 X 方向"需追加固定荷载 175.94kN"（NG），地震作用 X/Y
  方向需追加 0.00kN（OK）。
- **按方向抵抗力矩 Mr**、**按工况验算结果**（强度设计法/容许应力设计法等）：各卡片显示 Mo、安全系数
  S.F、KDS 组合式（例：0.9D+1.0W）、KDS 验算比、最大 ΔM_req、KDS 缺口抵抗力。例：风荷载 X 方向 —
  Mo 462.50kN·m、安全系数 S.F 0.74（NG）、KDS 组合 0.9D+1.0W、KDS 验算比 1.50（NG）、最大 ΔM_req
  351.89kN·m、KDS 缺口抵抗力 154.83kN。地震作用 X/Y 方向均为 OK（S.F 3.42、KDS 验算比 0.33）。
- **DETAILED CALCULATION**（详细计算结果）：按方向依次原样显示 `Mo = 462.50kN·m`、`Mr = ΣV × L =
  170.93 × 2.00 = 341.85 kN·m`、`S.F = Mr / Mo = 0.74`、`0.9D + 1.0W · 验算比 1.50`、`稳定所需
  ΣV = 346.87 kN`、`目标 ΣD.L = 260.47 kN`、"需追加固定荷载 175.94 kN"等算式 —— 计算过程不是黑箱，
  各步骤的公式与代入值均可确认。

### Step 4 — 输出报告

- 输入项目名、公司名（可选）后点击"打印/PDF"按钮。
- 报告（"抗倾覆稳定性验算计算书"）构成：1. 竖向荷载及抵抗力矩（ΣD.L/ΣW/ΣV 摘要、验算方法、Mr,x/
  Mr,y 算式），2. 倾覆验算概念图·钢结构（图形+数值摘要），3. 模型外元素的自重（3-1 基础自重、3-2
  墙体自重详表）等 —— 把输入条件·分析结果·验算结果·算定依据整理为 A4 文档。

## 7. 输入数据规格

- **Lx、Ly**：以质心为基准的力臂距离（m）。
- **验算方法**：KDS 荷载组合（强度设计法/容许应力设计法）及/或安全系数（SF_req，默认 1.5）。
- **模型外元素的自重**：基础（面积、厚度、单位重量）、墙体（平面总长、厚度、层高、单位重量）——
  0 个以上。
- **荷载工况映射**：风荷载 X/Y、地震作用 X/Y 分别选择 GEN NX 工况或直接输入 Mo。

## 8. 输出 / 生成结果

- 按方向·按验算方法的抗倾覆稳定性判定（OK/NG）、安全系数、KDS 验算比。
- NG 时"确保稳定所需追加的固定荷载"定量值。
- "抗倾覆稳定性验算计算书"A4 报告（打印/PDF）。

## 9. 限制事项与局限

- 画面直接显示出：像地震作用 Y 方向那样，所映射荷载工况的倾覆力矩被读取为 0 的情况确实会发生 ——
  荷载工况的选择是否与实际分析结果相符须由用户另行验证，Plug-in 不会自动推荐正确的工况（仅显示警告）。
- 按结构形式的倾覆概念图是"不影响计算"的纯报告插图，与实际抵抗力矩的算定逻辑（ΣV × L）无关 ——
  需注意避免用户将其误认为计算选项。不过由于这是 Plug-in 自己明示的内容，风险较低。
- 输入模型外元素的自重时，若重复输入模型中已包含的构件，存在抵抗力矩被高估的风险，Plug-in 会直接
  发出警告，但无法自动侦测是否存在这种重复。

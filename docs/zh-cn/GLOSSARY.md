## 4. 不译内容（硬约束）

1. **JSON 代码块内的一切**：Key、Value、枚举字符串（`"BEAM"`、`"CONC"`、`"GLOBAL X-POSITION"`）原样保留。JSON 块里的 `description` 字段属于官方原文，**不改**。
2. 代码标识符：`TYPE`、`MATL`、`SECT`、`NODE`、`ANGLE`、`STYPE`、`iMETHOD`、`bUseMt` 等 Key 名。
3. 端点与 URL：`/db/NODE`、`DESIGN/RC/KDS-41-20-2022/DCO`、`https://moa-engineers.midasit.com:443/gen`。
4. 产品与专有名词：MIDAS Gen NX、MIDAS Civil NX、MAPI-Key、Hyper-S、KDS 41 20:2022、AIK-SRC2K、EN 1992、AASHTO、Eurocode。
5. 文件路径、文件名、article ID（如 `35807178748569`）、日期、Jira 号（`MAPI-2484`）。
6. 上标脚注标记 `¹⁾ ²⁾ ³⁾` 原样保留。
7. 表格嵌套缩进标记：一级 `└`，二级「两个全角空格 + `└`」——保留，不改成别的符号。
8. Python / VBA / JS 代码：**语句不译**；行注释、docstring、`print` 文案中的韩文译为中文。译后代码必须仍可运行。

## 5. 标题与锚点

- 章节标题的**英文原題保留**，只把括注里的韩文换成中文：
  `## 1. \`DESIGN/RC/KDS-41-20-2022/DCO\` — Concrete Design Code Option (콘크리트 설계 코드 옵션)`
  → `## 1. \`DESIGN/RC/KDS-41-20-2022/DCO\` — Concrete Design Code Option (混凝土设计代码选项)`
- 英文固定小节标题不改：`### Specifications`、`### JSON Schema`、`### Request / Response JSON`、`## Table of Contents`、`### Active Methods`、`### Input URI`。
- 含韩文的小节标题译为中文：`### Python 예제` → `### Python 示例`；`### 파라미터` → `### 参数`；`## 공통 설정` → `## 通用设置`；`## 전체 워크플로우 예제` → `## 完整工作流示例`。
- **标题变了，页内 TOC 锚点必须同步改**。`docs/manual/24/25/26/27` 有 144 个含韩文的锚点，最易出错。
- 校验闸：`python scripts/manual_sync/validate_manual.py` 会**递归**校验 `docs/manual/` 与 `docs/plugin/`（含新增 `zh-cn/`），要求 JSON 块可解析、TOC 锚点可解析。基线为 0 错，译文不得引入新错误。

## 6. 译文来源块

每篇 `zh-cn` 译文在标题下方插入（紧接原「Source / 출처」块之后，若无则接在一级标题之后）：

```markdown
> **语言：** 简体中文译文  
> **原文：** [韩文原文]({{ORIGINAL}}) · **原文同步日期：** 2026-06-29  
> **译文生成：** 2026-09-21（机器辅助翻译，术语见 [GLOSSARY]({{GLOSSARY}})）
```

- `{{ORIGINAL}}`、`{{GLOSSARY}}` 是**占位符，原样照抄**，由 `fix_links.py` 按各文件实际深度替换为正确的相对路径。不要自己猜 `../` 层数。
- 同步日期从原文文件的 `Sync date` / `이 파일 동기화` 行取，不得凭空填写；原文无此信息时整行省略。

## 8. ⚠️ 依据注释必须保留

原文中 `> ⚠️` 注释承载「本文与官方原文不一致」的证据链（日期、article ID、locale 分歧、撤回记录）。翻译时：

- 逐条完整译出，**不得省略或简化**；
- 保留「原文」二字指代官方英文/韩文正文的语义，明确区分「en-us 原文」「ko 原文」；locale 分歧必须逐处标明；
- 例：`실제로 /ope/MEMB는 영문 요청 예제가 ELEM_LIST(표와 일치)인데 한글 요청 예제만 AELEM…` → 必须译出「英文请求示例为 `ELEM_LIST`（与表一致），仅韩文请求示例为 `AELEM`」这一对照关系，并保留 `MAPI-2484` A-7 撤回记录。

这些注释是后续官方站点同步时防「被改回」的唯一依据。

## 9. 相对链接（由脚本统一重写，翻译时不要动）

新增 `zh-cn/` 一层会破坏既有相对路径（`docs/plugin/tools/*.md` 里有 75 处 `../../manual/…`）。因此：

- **翻译时把方括号外的链接路径原样照抄**，不要自行加减 `../`、不要改成绝对路径、不要改写目标文件名。
- 全部译文写完后由 `scripts/zh-cn_localize/fix_links.py` 统一重写：解析出原目标 → 若该目标存在 `zh-cn` 镜像则指向镜像，否则指向原文件并按新目录深度重算相对路径。
- 锚点 `#…` 不在此范围内，**必须**由翻译者按 §5 同步改（脚本不碰 `#` 链接）。

## 10. 写作风格

- 用大陆工程文献语序，句末不用「입니다/합니다」对应体，直接陈述。
- 「합니다」体 → 无主语句或「本接口用于…」。
- 保留中文与英文/数字间不加空格的既有习惯。
- 计量单位：`m`、`kN`、`tonf`、`°` 原样；韩文「칸」→「跨」，「층고」→「层高」。
- 不添加原文没有的说明、不外链新资源、不改写技术判断。

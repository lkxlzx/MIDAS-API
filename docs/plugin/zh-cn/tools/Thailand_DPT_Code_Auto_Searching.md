## 概述

本 Plug-in 以泰国建筑所在地（府（Province）、县（District））为基准，快速、直观地检索 **DPT**（Department of Public Works and Town & Country Planning）设计代码。无需手动检索复杂的设计代码文档，只要在基于地图的界面中选择建筑位置，即可即时查看该区域的地震作用设计参数（Seismic Zone、Ss、S1）与风荷载设计参数（Wind Zone、Wind Speed、Typhoon Factor）。

## 支持版本

- `MIDAS GEN NX 2026 (v1.1) US`
- 适用标准：Thailand DPT (Department of Public Works and Town & Country Planning)

## 主要功能

- **节省时间：** 将手动检索设计代码文档、交叉查阅多张表格的时间压缩为一次点击。
- **准确的位置匹配：** 基于地图的选择可准确匹配府、县，避免位置错误。
- **可视化校验：** 所选区域在地图上可视化显示，位置确认直观。
- **双语支持：** 可自由切换泰语与英语，本地与海外用户均可便捷使用。

## 使用方法

| 步骤 | 说明 |
| --- | --- |
| 1 | 在页面左上方即时切换泰语、英语 |
| 2 | 在左侧下拉框中选择建筑所在的府（Province） |
| 3 | 在右侧下拉框中选择建筑所在的县（District） |
| 4 | 选择县后地图放大至该县，县域以橙色高亮显示 |
| 5 | 在地图旁的 **Detailed Information** 区查看 DPT 设计参数 |

## 参考/限制事项

- **语言选择：** 在页面上方 "Select Language / เลือกภาษา" 下拉框中选择 TH（泰语）或 EN（英语）。
- **府（Province）选择：** 可从泰国 77 个府中选择。选择时地图以该府为中心移动，府界线整体显示为蓝色。
- **县（District）选择：** 列表中仅显示所属所选府的县（随府的选择自动过滤），选择时地图放大至该县并以橙色高亮显示。
- **地图显示：** 为准确确认位置，地图自动以所选县为中心放大。
- **DPT 设计参数** — 地震作用：Seismic Zone（地震区划分类）、Ss（短周期谱响应加速度系数）、S1（1 秒周期谱响应加速度系数）。风荷载：Wind Zone（风速区划分类，例：4B、1 等）、Wind Speed（设计风速，m/s）、Typhoon Factor（台风强度倍率，TF）。

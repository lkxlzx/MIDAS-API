## 概述

本 Plug-in 按设定的时间间隔自动保存正在作业的模型，为建模文件提供自动保存功能。

## 支持版本

`MIDAS CIVIL NX 2024 (v1.1) US`

## 主要功能

- **自定义保存间隔：** 以分钟或小时为单位，按用户设定的间隔保存模型，在不打断作业的前提下防止重要文件数据丢失。
- **防止数据丢失：** 通过定期保存维持最新的备份状态，防止数据丢失。

## 使用方法

| 字段 | 说明 | 选项·默认值 |
| --- | --- | --- |
| 保存间隔（分钟） | 启用 AutoSaver Plug-in 并以分钟为单位设定保存间隔 | 默认值 `5分钟` |
| Auto Save 开关 | 启用后按设定的间隔自动保存建模文件 | — |
| OK | 点击后按设定保存模型文件 | — |

## 结论（原文）

Auto Saver Plug-in 按固定时间间隔自动保存变更内容，从而保护并管理项目。在需要频繁更新模型的环境中尤其有用，可使作业成果不致因中断而丢失。

## 访问路径

MIDAS Civil NX 的 **Apps → API 选项卡**中有 **Plug-in** 菜单。打开该菜单时，Plug-in 窗口以弹窗形式弹出。

## Plug-in 窗口构成

| 区域 | 说明 |
| --- | --- |
| Market Place | MIDAS 提供的 Plug-in 列表 |
| Saved Plug-ins | 在 Market Place 中安装的 Plug-in |
| My work | 用户自行开发的 Plug-in 上传区域 |
| Bookmark | 用户设为收藏的自定义文件夹。用户自己制作的 Plug-in 也可注册到此处并上传到 Market |
| Available contents | 直接显示当前可用的 Plug-in 内容 |

## 运行单个 Plug-in

选择所需的 Plug-in（例："Response Spectrum Generator"）后，会弹出介绍该 Plug-in 并引导下一步操作的弹窗。

| 项目 | 说明 |
| --- | --- |
| Version | Plug-in 版本。数字越大版本越新 |
| Add | 点击后保存在 **Saved Plug-ins** 之下 |
| Video Manual | 提供视频形式的使用方法说明 |
| README | 提供文档形式的使用方法说明 |
| Run | 运行 Plug-in |

点击 **Run** 按钮即运行 Plug-in，之后可直接使用该 Plug-in 的功能。

## 后续规划（Marketplace）

以原文撰写时点为准，MIDAS 方面说明正在准备一套系统，让用户可以上传自行开发的 Plug-in 并在 **Marketplace** 中共享。目标是反映国家/组织各不相同的业务流程，使用户之间、公司内部·外部都能共享 Plug-in。
